**Category:** Reporting / Efficiency
**Definition:** % reduction in time required to generate standard reports via automated BI tools.

**Formula:** (Baseline Time – Current Time) ÷ Baseline × 100

**Data Sources:** User logs, reporting platforms.

**Example Target / Benchmarks:** ≥50%.
