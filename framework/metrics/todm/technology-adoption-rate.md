# Technology Adoption Rate

**Category:** Organisational Capability
**Definition:** Percentage of staff and portfolio assets actively using digital and automated platforms.

**Why It Matters:** Measures digital transformation maturity and readiness for technology-driven improvements.

**Formula:** Users or Assets Using Tech ÷ Total Users or Assets × 100

**Data Sources:** User access logs, platform usage reports.

**Example Target / Benchmarks:** ≥80% adoption within 12 months of rollout.

**Enables:** Report Generation Time Reduction %
