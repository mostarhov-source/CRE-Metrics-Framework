# Asset Hierarchy Data Coverage %

**Category:** Portfolio Data / Quality
**Definition:** % of assets with a fully digitised hierarchy (portfolio → property → unit → lease → tenant) in the system.

**Why It Matters:** Ensures no gaps in portfolio visibility for reporting and analytics.

**Formula:** Fully Digitised Assets ÷ Total Assets × 100

**Data Sources:** ERP, property management DB.

**Example Target / Benchmarks:** ≥95%.

**Enables:** Asset Hierarchy Data Coverage % (BODM)
