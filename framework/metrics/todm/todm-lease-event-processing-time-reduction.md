# Lease Event Processing Time Reduction %

**Category:** Lease Management / Efficiency
**Definition:** % reduction in average time to process lease events (renewals, expiries, notices) through automated workflows.

**Why It Matters:** Prevents missed deadlines and improves tenant experience.

**Formula:** (Baseline Time – Current Time) ÷ Baseline × 100

**Data Sources:** Case management logs, workflow data.

**Example Target / Benchmarks:** ≥30% faster.

**Enables:** Lease Event Processing Time Reduction % (BODM)
