# Accuracy of AI-Generated Cost Estimates

**Category:** Development Tech / AI
**Definition:** Degree of alignment between AI-generated cost estimates and actual project costs.

**Why It Matters:** Validates reliability of AI planning tools for financial forecasting.

**Formula:** 1 – (|AI Estimate – Actual Cost| ÷ Actual Cost)

**Data Sources:** AI estimate logs, actual project costs (ERP).

**Example Target / Benchmarks:** ≥90% accuracy.

**Enables:** Gross Development Value (GDV) Optimisation
