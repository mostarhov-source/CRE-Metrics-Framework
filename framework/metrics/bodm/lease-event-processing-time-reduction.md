# Lease Event Processing Time Reduction %

**Category:** Operational Efficiency
**Definition:** % reduction in average processing time for lease events (renewals, expiries, notices).

**Why It Matters:** Minimises missed deadlines and improves tenant management.

**Formula:** (Baseline Time – Current Time) ÷ Baseline × 100

**Data Sources:** Workflow logs, case management.

**Example Target / Benchmarks:** ≥30% faster.
