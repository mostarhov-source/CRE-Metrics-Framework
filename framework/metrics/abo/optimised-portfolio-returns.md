# Optimised Portfolio Returns

**Category:** Aggregated Business Outcome
**Definition:** Improved financial performance and return on investment across the CRE portfolio, from acquisition through disposition.

**Why It Matters:**
- Core objective of asset management and investment strategy.
- Directly linked to investor confidence and ability to raise capital.
- Guides buy/hold/sell decisions at the portfolio level.

**Example Indicators:**
- IRR, NPV, Equity Multiple, NOI growth.
- Portfolio yield vs benchmark index.
- Asset-level return contribution to overall fund.

**Example Evidence / Benchmarks:**
- Core CRE portfolios target 8–12% IRR.
- Opportunistic / value-add portfolios often target >15%.
