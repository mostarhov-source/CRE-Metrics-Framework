# Ryman Online Print — Step-by-Step Instructions

**URL:** ryman.co.uk → Print & Copy → Document Printing

---

## What you need before you start

- [ ] `output/flashcards-YYYY-MM-DD.pdf` generated and saved locally
- [ ] `output/facilitation-script-YYYY-MM-DD.pdf` generated and saved locally
- A Ryman account (free to create at checkout)

---

## Order 1 — Flashcard Deck (A6 cards)

### Step 1 — Go to the print page
Navigate to: **ryman.co.uk → Print & Copy → Document Printing → Upload & Print**

### Step 2 — Upload the file
Click **Upload File** and select `flashcards-YYYY-MM-DD.pdf` from your `flashcards/output/` folder.

### Step 3 — Set print options

| Option | Selection |
|---|---|
| **Document size** | A6 |
| **Orientation** | Portrait |
| **Print type** | Colour |
| **Sides** | Double-sided |
| **Binding edge** | Short edge (flip on short edge) |
| **Paper type** | Card |
| **Paper weight** | 350 gsm |
| **Finish** | Matt laminate |
| **Copies** | 1 (or more if printing for multiple facilitators) |

> **If A6 is not listed as a size option:** Select A4 and call your nearest Ryman branch to confirm they can cut to A6. Most larger branches have guillotine cutters. Alternatively, export the PDF at A4 with crop marks and ask them to cut — add a note in the order comments.

> **If 350 gsm is not available online:** Select the heaviest card option listed (usually 300 gsm or 350 gsm silk). Call the branch if unsure.

### Step 4 — Review the preview
Ryman's uploader shows a page preview. Check:
- Chain colour stripe is visible at the top of card fronts
- Text is not cut off at card edges
- Page count matches expected (160 pages = 80 cards × 2 sides)

### Step 5 — Add to basket
Click **Add to Basket**. Check the order summary shows:
- A6, colour, double-sided, 350 gsm, matt laminate
- Correct quantity

### Step 6 — Choose delivery or collection
- **Click & Collect** — ready in 1–2 working days at your chosen branch (free)
- **Delivery** — 2–3 working days to your address

### Step 7 — Checkout
Complete checkout. You will receive an order confirmation email. Production typically starts the next working day.

## Order 2 — Facilitation Script (A4)

Place this as a **separate order** or print yourself — it does not need card stock or lamination.

| Option | Selection |
|---|---|
| **Document size** | A4 |
| **Orientation** | Portrait |
| **Print type** | Black & white (colour is fine too) |
| **Sides** | Single-sided |
| **Paper type** | Standard paper |
| **Paper weight** | 80 gsm |
| **Copies** | 2–3 |

> Alternatively, print the facilitation script on any office or home printer — it does not need professional finishing.

---

## Tips

- **Order early.** Allow 2–3 working days before your facilitation session.
- **Proof one card first.** If printing a large run for multiple sessions, order 1 copy first, check the physical card, then reorder in bulk.
- **Keep the PDF dated.** If you regenerate the cards after changing metrics, the new file gets a new date — you'll never accidentally send the wrong version.
- **Matt laminate is essential.** Participants write on the card backs (Before AI / After AI / By when). Gloss laminate prevents ink from adhering — always specify matt.
